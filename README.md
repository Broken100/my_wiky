# Biblioteca de conocimiento

Esta bóveda reúne fuentes originales y conocimiento que se desarrolla a partir de ellas. Abre [Inicio](Inicio.md) para comenzar o consulta el [índice](indice.md) para navegar.

## Estructura

- `fuentes/`: documentos originales y sus adjuntos, conservados sin modificar.
- `wiki/fuentes/`: resúmenes procesados con referencias a los originales.
- `wiki/temas/`: páginas que conectan y sintetizan conocimiento.
- `fuentes/adjuntos/`: destino automático de los nuevos adjuntos insertados desde Obsidian.
- `indice.md`: navegación central por fuentes y temas.
- `registro.md`: historial acumulativo de operaciones.
- `AGENTS.md`: reglas de mantenimiento para Codex.
- `Inicio.md`: portada y guía rápida.

Los adjuntos que forman parte de una fuente original pueden guardarse en `fuentes/` junto con ella. Obsidian guarda los adjuntos nuevos que insertes en notas en `fuentes/adjuntos/`; si alguno es parte de una fuente original, consérvalo sin modificar y enlázalo desde el resumen.
