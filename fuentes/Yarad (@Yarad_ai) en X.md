	Anthropic está enviando un mensaje importante: ¡no uses Claude Code solo para programación! Esta compañía ha lanzado 11 plugins de código abierto que preparan a Claude para actividades en diversos campos laborales. Estos plugins cubren diversas áreas, entre ellas: - Ventas: ayuda en el proceso de ventas, gestión de clientes y seguimiento de oportunidades de venta - Marketing: planificación de campañas, producción de contenido y análisis de actividades de marketing - Legal: ayuda en la revisión de documentos, contratos y procesos jurídicos - Finanzas: análisis de información financiera y realización de tareas relacionadas con asuntos financieros - Análisis de datos: examen de datos, análisis de información y extracción de insights - Gestión de productos: gestión de productos, revisión de requisitos y planificación de desarrollo ¿Exactamente qué le proporciona cada plugin a Claude? Cada uno de estos plugins contiene un conjunto de tres secciones: 1. Habilidades: instrucciones y conocimiento especializado para realizar tareas de cada área. 2. Comandos: instrucciones predefinidas para ejecutar rápidamente trabajos específicos. 3. Conectores: conexión a herramientas y servicios relacionados para que Claude pueda participar en flujos de trabajo reales. En realidad, en lugar de tener que explicarle a Claude desde cero cada vez cómo debe trabajar un especialista en ventas, marketing o análisis de datos, puedes proporcionarle el plugin relacionado para que opere con el flujo de trabajo de esa área. Punto importante: este enfoque eleva a Claude Code más allá de una herramienta meramente de programación y lo convierte en un asistente especializado para realizar tareas profesionales.
